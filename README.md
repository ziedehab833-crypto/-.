# أتوبيس كمبليت PRO — ملفات النشر

## محتويات الحزمة
- `server.js`: سيرفر PeerJS مع Express ومسار فحص `/health`.
- `package.json`: اعتماديات Node.js وأمر التشغيل.
- `render.yaml`: إعداد نشر Render.
- `index.html`: اللعبة بعد تجهيزها للاتصال بسيرفرك.

## نشر السيرفر من الهاتف

1. فك ضغط الملف.
2. ارفع محتويات المجلد إلى مستودع GitHub جديد (يجب أن يكون `package.json` و`server.js` و`render.yaml` في جذر المستودع).
3. افتح Render وأنشئ Web Service جديداً، ثم اربط مستودع GitHub.
4. Render يقرأ `render.yaml`. تأكد أن أمر البناء `npm install` وأمر التشغيل `npm start`.
5. بعد نجاح النشر انسخ نطاق الخدمة، مثل `autobus-peerjs.onrender.com`.

## ربط اللعبة بالسيرفر

افتح `index.html` وابحث عن:
`YOUR-RENDER-SERVICE.onrender.com`

استبدله بالدومين الذي أعطاك Render فقط، بدون `https://` أو مسارات. مثال:
`autobus-peerjs.onrender.com`

احفظ الملف ثم ارفع اللعبة إلى استضافة صفحات ثابتة تدعم HTTPS، أو افتحها من استضافة الويب التي تستخدمها.

## اختبار السيرفر
افتح:
`https://YOUR-RENDER-SERVICE.onrender.com/health`

المفروض يظهر رد JSON فيه `ok: true`.

## ملاحظات مهمة
- لم يتم نشر السيرفر فعلياً؛ النشر يحتاج تسجيل الدخول إلى حساب GitHub وRender وموافقتك على إنشاء الخدمة.
- خدمة Render المجانية قد تتوقف مؤقتاً بعد فترة خمول، وأول اتصال بعدها قد يتأخر.
- PeerJS Server مسؤول عن الإشارات فقط. اتصال الصوت/البيانات المباشر بين بعض الشبكات قد يحتاج TURN server منفصلاً.
- لا تضع كلمات مرور أو مفاتيح خاصة داخل ملف HTML.
- خادم الإشارات لا يخزن نتائج اللعبة أو الحسابات؛ بيانات الجولة تمر بين اللاعبين والهوست.
